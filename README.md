# Cozy Life Planner — bản giao diện thử nghiệm

Giao diện song ngữ Việt–Trung, tương thích điện thoại và máy tính.

## Đưa lên GitHub Pages
1. Tạo repository `cozy-life-planner`.
2. Upload `index.html`, `style.css`, `app.js` vào thư mục gốc của repository.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Chờ GitHub hoàn tất deployment rồi mở URL GitHub Pages trong Settings → Pages.

**Cảnh báo:** Phiên bản này chỉ là demo, lưu dữ liệu vào localStorage của từng trình duyệt. Chưa có Supabase Auth, RLS, Realtime, đồng bộ đa thiết bị hoặc bảo mật dữ liệu cá nhân. Không nhập dữ liệu riêng tư thật. Không upload khóa `service_role` hay secret key lên GitHub.
